# AI notice

This fork adds code that was written with AI assistance. Large parts were generated by Claude (Anthropic) in
conversation with the fork's owner, who directed the design, built it and tested it on their own Switch.

- **MissionControl itself** is the work of ndeadly and contributors and is not AI-generated.
- **The `ds4-lightbar-remap-livereload` changes to `mc_mitm/`** (DS4 lightbar colour, button remapping, live reload of
  `missioncontrol.ini`) were AI-generated. The exact changes are in the commit "DS4: custom lightbar colour, button
  remapping, live ini reload" and can be reviewed with `git show`.
- **`ds4color-setup/`** (the "DS4 Controller Setup" homebrew app) was AI-generated.

Testing so far: the sysmodule and the app compile with devkitPro, and the patched sysmodule boots and works with a
DualShock 4 on real hardware. The config parser and button-mapping logic were also checked on a PC against stubs of the
libstratosphere calls, and the app's UI/ini layer has a host test (`ds4color-setup/test/run.sh`). Live colour and
binding changes from the app have not all been verified on hardware, and one unexplained input-delay hiccup has been
reported.

This runs as a sysmodule on a modified console. Back up your SD card (especially
`atmosphere/contents/010000000000bd00/`) before installing, and review the diff if you want to know exactly what it does.
